ACADEMIA HOUSE WEBSITE
======================

This folder is a complete static website for the Academia, Windhoek property.

Open locally:
1. Double-click index.html, or open it in any modern web browser.
2. Keep the images folder beside index.html.

Publish online:
- Upload index.html and the images folder to any static website host such as GitHub Pages, Netlify, Cloudflare Pages or your existing web host.
- No database or server-side software is required.

The enquiry buttons use the telephone numbers and email addresses already supplied in the website content.
